Product Concept

SafeSignal

An always-on home check-in hub for elderly independence — no smartphone, no charging, no stigma

How It Works

The full loop — from normal day to emergency response — in 6 clear steps

1
🌅
Daily Activation
Device glows green each morning at a set time (e.g. 8 am). Senior just needs to press the button once — "I'm okay."
→
2
✅
Check-In Sent
Signal is sent instantly via 4G LTE cellular to the cloud. Family app shows "Mum checked in — 8:14am".
→
3
⏰
Missed Window
If no check-in by 9:30am, the device speaks aloud — "Would you like to check in?" and glows amber.
→
4
📲
Family Alert
Still no response after 15 min? Family receive a push notification + SMS simultaneously. Escalation ladder begins.
→
5
🆘
SOS Button
At any time, long-press 3 seconds to trigger an immediate SOS — calls family first, then emergency services if unanswered.
→
6
📞
Two-Way Call
Family can call back through the device — it has a built-in speaker + mic. No phone needed by the senior.

What Makes SafeSignal Different

The 4 core problems existing products haven't solved — and how SafeSignal solves each one

❌ Every Competitor's Problem

  • 86% of wearables end up in a drawer — they feel like medical devices
  • Smartwatches need daily charging — forgotten by cognitively declining users
  • Check-in apps need a smartphone — 40% of 75+ don't own one
  • GPS trackers only respond to emergencies — no daily wellness routine
  • Medical pendants carry a "I've fallen" social stigma
  • Monthly fees of $30–40 feel expensive for a "just in case" device
  • 80% of dangerous falls happen when the wearable isn't being worn

✅ SafeSignal's Answer

  • Looks like a kitchen appliance (Google Home aesthetic) — zero stigma
  • Plugged into mains power — never needs charging, always ready
  • One physical button — works for anyone, no digital literacy required
  • Daily ritual creates habit — press green = "I'm okay" every morning
  • Passive home monitoring — no wearable means 100% coverage at home
  • $6–9/month SIM plan — 4–5x cheaper than most PERS subscriptions
  • Built-in speaker = family can call back through the device directly

Concept A — "The Puck"

Sits on the kitchen bench. Looks like a Google Home Mini.

  • Matte white or charcoal finish — looks like a speaker
  • Speaker grille around base for two-way voice
  • USB-C power — plugs into kitchen socket

Concept C — "The Band"

For active seniors or those who travel. Looks like a watch.

  • Leather or silicone strap — looks like jewellery, not medical
  • 30-day battery (e-ink display) — no daily charging anxiety
  • Side button for SOS long-press
  • GPS for location if senior goes out or gets lost
  • Pairs with the same family app as Concept A
  • Best for mild dementia / wandering risk
  • BOM cost: ~$55–70 | Retail: $129

Hardware & Tech Stack to Build It

Everything needed to go from idea to working prototype

🔧

Hardware (Prototype)

  • → ESP32 microcontroller (~$5)
  • → SIM7600 4G LTE module (~$18)
  • → 60mm tactile button, backlit (~$3)
  • → LED ring / NeoPixel strip (~$4)
  • → 3W speaker + I2S amp (~$5)
  • → MEMS mic for voice (~$2)
  • → USB-C power input (~$1)
  • → Total BOM: ~$38–50
☁️

Backend / Cloud

  • → Supabase (Postgres + real-time)
  • → Twilio (SMS + voice calls)
  • → Firebase Cloud Messaging (push)
  • → MQTT over cellular for device comms
  • → Scheduled jobs: check-in windows
  • → Escalation state machine (Node.js)
  • → Cloud cost: ~$2–3/device/month
📱

Family App

  • → React Native (iOS + Android)
  • → Push notifications (FCM / APNs)
  • → Real-time status via WebSocket
  • → SMS fallback (no app needed)
  • → WhatsApp Business API option
  • → No login needed for elderly side
  • → Dev time: ~6–8 weeks MVP
💰

Business Model

  • → Device: $89 one-time (retail)
  • → Plan: $7.99/month (SIM + cloud)
  • → Cost to serve: ~$3/mo → 62% margin
  • → Target: families of 75+ seniors
  • → Channel: Amazon, pharmacies, GP offices
  • → Gift purchase model (adult children buy)
  • → LTV at 3yr: ~$377/device
